## Project Description

Razorpay is a responsive frontend payment gateway website developed using HTML, CSS and JavaScript.

The project was created as part of the **QSkill Internship Slab 2 Intermediate Web Development Task**, which required developing a frontend implementation inspired by a modern payment platform website.

The website focuses on payment gateway interfaces, business banking, pricing plans, payment products and responsive navigation.

## Features

* Responsive navigation bar
* Mobile hamburger menu
* Hero section
* Payment dashboard UI
* Trusted businesses section
* Payment gateway section
* Secure checkout UI
* Payment Links
* Invoices
* Subscription management section
* Business banking section
* Transaction dashboard
* Analytics section
* Security section
* Pricing plans
* Call-to-action section
* Responsive footer
* Smooth scrolling
* Button interaction using JavaScript
* Mobile responsive design

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. The PayFlow website will load directly.

No backend or database is required for this project.
